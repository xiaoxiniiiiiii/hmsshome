# HMSS Home

汝州市帆灵商贸行（个体工商户）的 React + Vite 百货家居商城前端演示。

## Run

```bash
npm i
npm run dev
```

## Included

- 5 collections, 16 products per collection (80 products total)
- Add to Cart opens the side bag
- Buy Now adds the product and opens checkout
- PayPal, Visa and credit-card checkout options as frontend demo states
- About, shipping, tracking, payment, returns, cancellation, Terms of Service (17 sections), privacy and DMCA pages
- Frontend-only staff dashboard at the Staff login link

Demo staff login: `demoadmin` / `HmsHome#2026!`

Payment processing, order persistence, account authentication and staff authentication are not connected to a backend. Replace the demo states with server-side services before production use.
